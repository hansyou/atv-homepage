# ATV Homepage · Apple TV 风格个人主页

部署在 Cloudflare Workers 上的个人主页：首屏精简（7 个快捷网址），下滑进入类似 Apple TV 的 App 启动台，支持网址新建 / 编辑 / 归入文件夹，管理操作需密码验证，支持全站数据备份与恢复。

> 技术架构、数据模型、API、本地开发等开发向内容见 [AGENTS.md](./AGENTS.md)。

---

## 1. 功能介绍

### 1.1 首页（精简首屏）

Apple TV 待机页气质：深色背景 + 模糊光晕，中间留白，图标贴底。

- **顶部状态行**：问候语 + 时钟，可在「站点设置」里关闭时钟或加一句小字备注。
- **中央搜索框**：默认必应，左侧可切换百度 / 谷歌（选择记在浏览器本地），回车或点放大镜在新标签页搜索。
- **底部图标坞**：最多 7 个快捷网址（首页快捷位），大图标 + 名称，悬停放大、点击新标签打开；未配置图标时用名称首字生成渐变占位图。
- **背景壁纸**：默认 macOS 风格浅绿渐变壁纸，可在「管理内容 → 站点」自定义（图片链接或上传本地图片），清空后回退深色渐变。

### 1.2 启动台（下滑进入的第二屏）

Apple TV App 网格：所有网址的响应式图标网格。

- 卡片悬停放大 + 光晕，键盘可聚焦；文件夹显示堆叠图标，点击弹出半透明浮层查看内部网址。
- 登录后可**拖拽排序**、把网址**拖入文件夹**归类（桌面端）；移动端用管理面板编辑。
- 未登录只能浏览，点击「管理」弹出密码框。

### 1.3 管理功能（登录后）

- **新建 / 编辑网址**：点启动台的「新建网址」或卡片上的铅笔按钮，弹出**独立编辑弹窗**（标题、URL、图标链接（选填）、所属文件夹、是否置入首页 7 个快捷位），保存 / 取消后自动关闭。
- **新建 / 编辑 / 删除文件夹**：同上，弹窗内填名称、主题色。
- **站点设置 / 备份**：点击「管理内容」弹出管理抽屉（仅此入口，登录后不会自动弹出）：标语小字、时钟开关、壁纸；备份导出 / 恢复 JSON。

## 2. 使用方法

### 2.1 访客

1. 首页搜索框输入关键词回车 → 新标签页搜索（可切换必应 / 百度 / 谷歌）。
2. 点击底部快捷图标 → 新标签页打开对应网址。
3. 下滑（或点底部下箭头）→ 进入启动台，点击图标打开网址、点击文件夹查看内部网址。

### 2.2 管理员

1. 点击「登录管理」→ 输入管理密码登录（密码在部署时设置，见 §3），登录成功后自动回到页面。
2. **添加网址**：启动台「新建网址」按钮（弹出编辑弹窗），填标题与 URL；图标链接留空则自动生成首字占位图；勾选「置入首页」可占据 7 个快捷位之一。
3. **整理归类**：新建文件夹（可选主题色），把网址选入文件夹；或在启动台编辑模式下直接把网址卡片拖到文件夹上。
4. **排序**：点击「编辑顺序」进入编辑模式（图标抖动），按住卡片拖动调整位置，完成后点「完成」；也可长按卡片进入编辑模式。
5. **删除**：编辑模式下点卡片右上角的删除按钮，确认后删除（删除文件夹时内部网址会移出到启动台顶层）。
6. **备份 / 迁移**：「管理内容 → 备份」导出 JSON；在新站点粘贴或上传该 JSON 即可整体恢复（覆盖现有数据，需二次确认）。
7. **站点设置**：「管理内容 → 站点」修改标语小字、时钟开关、壁纸。

### 2.3 内容更新与部署的关系

| 场景                               | 操作                                                                              |
| ---------------------------------- | --------------------------------------------------------------------------------- |
| 改网址 / 文件夹 / 壁纸等**内容**   | 站内「管理」面板改，数据存 D1，**不需要重新部署**                                 |
| 改**代码**（界面 / 逻辑）          | `pnpm run deploy`                                                                 |
| 改**默认数据**（首次初始化的示例） | 改 `schema.sql` 后 `pnpm run db:init`（`INSERT OR IGNORE`，不会覆盖线上已有数据） |
| 换管理密码                         | `pnpm exec wrangler secret put ADMIN_PASSWORD`                                    |
| 换机器 / 迁移数据                  | 站内「管理 → 备份」导出 JSON，新站点「恢复」导入                                  |

## 3. 部署到 Cloudflare Workers

配置文件 `wrangler.jsonc` 位于项目根目录（Static Assets + Worker + D1 随同一配置发布）。

### 3.1 前置条件

- Node.js 20+ 与 pnpm
- 一个 Cloudflare 账号（免费版即可，Workers / D1 免费额度足够个人主页使用）

### 3.2 首次部署（共 6 步）

```bash
# 1. 安装依赖
pnpm install

# 2. 登录 Cloudflare（二选一）
pnpm exec wrangler login                 # 方式 A：浏览器授权（本地部署推荐）
source .env                              # 方式 B：API Token（CI / 服务器部署，见下方说明）

# 3. 创建 D1 数据库，把返回的 database_id 填入 wrangler.jsonc
pnpm exec wrangler d1 create atv-homepage

# 4. 初始化线上数据库表结构 + 默认数据（Cloudflare + GitHub 示例、默认壁纸）
pnpm run db:init

# 5. 设置管理密码（部署后用于登录管理面板）
pnpm exec wrangler secret put ADMIN_PASSWORD

# 6. 构建前端并发布
pnpm run deploy          # = vite build web && wrangler deploy
```

发布成功后访问 `https://atv-homepage.<你的子域>.workers.dev` 即可。

> **方式 B（API Token）说明**：`.env` 模板里放 `CLOUDFLARE_API_TOKEN` 与 `CLOUDFLARE_ACCOUNT_ID`，
> `source .env` 后 wrangler 无需浏览器登录即可部署。Token 在 Cloudflare 控制台 →
> 「我的个人资料 → API 令牌」创建，权限给 `Edit Cloudflare Workers`。
> ⚠️ `.env` 含密钥，已加入 `.gitignore`，**不要提交到仓库**。
> 本地开发的管理密码写在 `.dev.vars`（见 AGENTS.md）。

### 3.3 自定义域名

Cloudflare 控制台 → **Workers & Pages** → 选中 `atv-homepage` → **Settings → Domains & Routes** → **Add** → 输入你的域名。
域名 DNS 托管在 Cloudflare 时一键 CNAME 生效，无需额外配置。

### 3.4 常见问题

| 现象                                          | 原因 / 解决                                                            |
| --------------------------------------------- | ---------------------------------------------------------------------- |
| 部署时报 D1 相关错误                          | `wrangler.jsonc` 里的 `database_id` 还是占位值，替换成第 3 步创建的 ID |
| 管理面板登录报「服务端未配置 ADMIN_PASSWORD」 | 没执行第 5 步，或 secret 设到了别的 Worker 名下                        |
| 页面 404 / 白屏                               | 先 `pnpm run build` 生成 `web/dist` 再部署                             |
